# Open threads

Run when the operator says "open threads" or "collect followups".
List every open thread from this session: followups, recommendations not acted on, bugs or suggestions found but not filed, review advisories, and questions no sd note holds yet.
Budget: about 15 minutes. Follow `references/decide-ask-record.md` to decide, ask, record and report; this run's tag is `open-threads`.

0. Report what the previous run's items became, as that file says.
1. File each unfiled one as an sd item in its repo, with that file's filing command and `--ref open-threads:<date>:<slug>`, or as a note on an existing item.
2. Rule the routine ones and ask the rest, as that file says. A question goes on the item step 1 filed or noted, so its answer has a note to answer.

End with a table: item, what it is, ruling or answer, next step; then the veto table and the line `RESULT: filed <n>, built <n>, asked <n>`.
